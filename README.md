

### ✅ **Nom du projet**

**TaskHub**
*(Simple, moderne, clair et évocateur d'un point central de gestion des tâches.)*

---

### 📝 **Description du projet (EN)**

**TaskHub** is a Git-powered task management system designed for agile teams. Built with **Spring Boot** for the backend and **Angular** for the frontend, TaskHub enables two user roles: **Admin** and **Employee**. Admins can create, update, assign, and comment on tasks, while Employees can view their tasks, update statuses, and collaborate with comments. With integrated search and streamlined UI, TaskHub empowers team productivity and project traceability.

### 🧩 **Fonctionnalités principales à implémenter**

### 🔧 **Stack Technique**

* **Backend** : Spring Boot (REST API, Spring Data JPA)
* **Base de données** : MySQL
* **Frontend** : Angular + Angular Material
* **Outils** : Git, Postman, Visual Studio Code, Docker (optionnel)
* **Modélisation** : UML (diagrammes de classe, cas d’utilisation, séquence)
